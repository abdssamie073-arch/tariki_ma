TARIKI PWA — ملفات التطبيق

المحتويات:
- index.html: واجهة التطبيق والوظائف.
- manifest.webmanifest: معلومات التثبيت والأيقونة وطريقة العرض.
- sw.js: Service Worker لتخزين ملفات التطبيق وتشغيله أوفلاين بعد أول زيارة.
- icons/: أيقونات 192 و512.

طريقة النشر المجاني باستعمال GitHub Pages:
1) فك ضغط TARIKI-PWA.zip.
2) أنشئ Repository جديد في GitHub.
3) ارفع جميع الملفات والمجلدات الموجودة داخل TARIKI-PWA إلى جذر المستودع (ليس ملف ZIP نفسه).
4) من Settings ثم Pages، اختر Deploy from a branch، ثم branch: main و folder: /(root)، واضغط Save.
5) انتظر حتى يظهر رابط الموقع. يجب أن يكون HTTPS.
6) افتح الرابط في Chrome أو Edge على Windows أو Chrome على Android.

طريقة التثبيت:
- Windows: افتح الرابط في Chrome أو Edge. اضغط أيقونة Install في شريط العنوان أو زر "تثبيت التطبيق" إذا ظهر.
- Android: افتح الرابط في Chrome، اضغط ⋮ ثم Install app أو Add to Home screen.

ملاحظات:
- التثبيت يحتاج استضافة HTTPS (أو localhost أثناء التطوير).
- التطبيق يشتغل دون إنترنت بعد أول تحميل ناجح للملفات.
- البيانات الحالية محفوظة محلياً على نفس الجهاز والمتصفح باستعمال localStorage؛ لا تنتقل تلقائياً بين هاتفك وحاسوبك أو بين المستخدمين.
- خط Cairo الخارجي يحتاج الإنترنت أول مرة، ويمكن استبداله بخط محلي إذا أردت عملاً أوفلاين كاملاً.
- لا ترفع كلمات مرور أو معلومات حساسة في هذه النسخة؛ لا يوجد نظام حسابات أو مزامنة سحابية.
